# Documentación técnica de OSP

Esta carpeta reúne la documentación del núcleo de Open Source Physics.

## Índice

- [Estructura de carpetas raíz](carpeta-raiz-osp.md): explicación de las carpetas principales del proyecto: `ant`, `src`, `bin`, `docs` y el espacio de paquetes `org`.
- [Mapa exacto de paquetes](paquetes-osp.md): descripción detallada de cada subcarpeta del paquete `org.opensourcephysics`.
- [Flujo de una simulación](flujo-simulacion.md): explicación del ciclo de ejecución desde el arranque hasta el paso de integración numérica.
- [Cómo construir una simulación](como-construir-simulacion.md): guía práctica para crear una simulación OSP desde cero.

## ¿Qué cubre esta documentación?

La documentación de esta carpeta explica la arquitectura del proyecto desde dos puntos de vista:

1. la organización de paquetes y módulos
2. el flujo real de ejecución de una simulación

Esto permite entender tanto la estructura conceptual del proyecto como el comportamiento interno de una simulación típica.
